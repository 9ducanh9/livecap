# Frontend Environments (Superseded)

This document described an earlier frontend-only preview split where Stable and
Preview shared one backend. Do not use it for a new deployment.

The isolated frontend and backend runtime design is documented in
`frontend-runtime-environments.md`. That replacement is currently untracked
work owned by another contributor, so this small compatibility document remains
until the replacement is committed. Delete this file in the same scoped change
that adds the replacement.
